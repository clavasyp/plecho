# ПЛЕЧО

Симулятор грузовой логистики. Браузер, изометрия, реальная Россия, 1994 → 2030-е.

Ты поднимаешь автотранспортную компанию с одного убитого ЗИЛа до федеральной
сети, связывая заводы, элеваторы, НПЗ и города в работающую промышленную цепь —
против конкурента, которым управляет языковая модель.

> Название — от транспортного плеча, участка маршрута между двумя точками.

## Что это за игра

Не биржа заказов «отвези A→B за N рублей». Экономический симулятор, где мир
зависит от игрока: предприятие останавливается, если не вывозить его продукцию
или не подвозить сырьё; город растёт, только если его снабжают; выросший город
требует больше — и твоя сеть перестаёт справляться.

Игрок не выполняет задания. Игрок создаёт экономику и чинит её узкие места.

**Ядро — обратная загрузка.** Главный вопрос не «какой рейс выгоднее», а «какая
цепочка замкнётся в кольцо так, чтобы ни одно плечо не шло порожняком». Процент
порожнего пробега — единственная метрика, отличающая мастера от новичка.

## Стек

- **Vite + React 19 + TypeScript**
- **Three.js** через React Three Fiber, постпроцессинг
- **Zustand** — состояние приложения
- **Vitest** — экономика и симуляция
- **Playwright** — самопроверка сцены
- **Gemini API** — конкурент под управлением языковой модели

## Главное архитектурное правило

`src/sim/` — чистый TypeScript. Ноль импортов React, Three.js и DOM. Симуляция
запускается в Node без браузера.

Это даёт: тесты экономики без окружения, прогон тысяч игровых лет за секунды для
настройки баланса, детерминизм, сохранения как обычный JSON, воспроизведение
багов по сохранению.

Правило охраняется тестом [`tests/sim-purity.test.ts`](tests/sim-purity.test.ts),
а не правилом линтера — тест нельзя отключить комментарием.

## Структура

```
src/
  sim/          чистая симуляция — ноль зависимостей от среды
    world/      граф дорог, проекция, поиск пути
    economy/    производство, потребление, рынок, финансы
    logistics/  машины, линии, диспетчеризация, водители
    ai/         конкуренты: скрипт и адаптер к модели
  data/         города, дороги, предприятия, рецепты, техника
  render/       R3F сцена — читает состояние, не содержит логики
  ui/           интерфейс
  app/          игровой цикл, хранилище, сохранения
tests/
  e2e/          Playwright
prompts/        лог промптов генерации ассетов
```

## Разработка

```bash
npm install
npm run dev
```

| Команда | Что делает |
|---|---|
| `npm run dev` | Дев-сервер |
| `npm test` | Тесты симуляции |
| `npm run test:watch` | То же в режиме наблюдения |
| `npm run e2e` | Playwright: сцена, консоль, скриншот |
| `npm run build` | Продакшен-сборка |
| `npm run check` | Линтер, сборка и тесты разом |

## Роль ИИ в разработке

Проект пишется через Claude Code: человек задаёт направление, проектирует и
ревьюит, модель реализует. Ассеты — текстуры, иконки, звук, музыка, тексты —
генерируются нейросетью, промпты складываются в [`prompts/`](prompts/).

Вся геометрия мира генерируется кодом, ни одной 3D-модели руками или через
text-to-3D.
