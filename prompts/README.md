# Промпты генерации ассетов

Здесь лежит лог того, чем и как сгенерирован каждый ассет в проекте. Файл на
категорию, внутри — промпт, модель, дата, куда лёг результат.

Смысл в воспроизводимости: любой ассет можно перегенерировать или подправить,
не вспоминая, как он получился. Заодно это честная документация роли ИИ в
проекте.

## Формат записи

```markdown
## <имя ассета>

- **Модель:** <какая>
- **Дата:** ГГГГ-ММ-ДД
- **Результат:** src/assets/<путь>

Промпт:

> <текст промпта дословно>

Заметки: <что пришлось править, какие итерации были>
```

## Категории

| Файл | Содержимое |
|---|---|
| `textures.md` | Покрытия, поверхности, рельеф |
| `skyboxes.md` | Небо по времени суток и погоде |
| `ui.md` | Иконки грузов, интерфейс, логотипы компаний |
| `audio.md` | Звук и музыка |
| `text.md` | Тексты, названия, реплики конкурента |

Файлы заводятся по мере появления ассетов — пустых заготовок не держим.
