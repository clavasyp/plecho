# «ПЛЕЧО» — план реализации

Принцип: **архитектура спроектирована целиком, вехи описаны крупно, ближайший
срез — детально.** Детальный план на десять срезов вперёд устареет после первого
же, потому что половину решений мы узнаем только на практике.

Каждый срез — вертикальный: в конце игра запускается и работает целиком, просто
уже по возможностям. Никаких «доделаем интерфейс потом».

---

## Принцип про визуал

**Арт-дирекшн ставится в первом же срезе, а не в конце.** Палитра, свет,
постпроцессинг, стилевой замок — всё это дёшево включить сразу и дорого
прикручивать потом к готовому уродству.

Практический смысл: любой скриншот на любом этапе выглядит прилично. Для
портфолио это критично — заявка подаётся из промежуточного состояния.

## Срез 1: Мир и движение

Детально. Дальше не расписываю — узнаем на практике.

### Данные

- [ ] `data/cities.ts` — 10 городов ЦФО: Москва, Тула, Рязань, Калуга, Тверь,
      Владимир, Ярославль, Смоленск, Брянск, Орёл. Координаты, население, профиль
- [ ] `data/roads.ts` — граф рёбер по реальным трассам: М-1, М-2, М-3, М-4, М-5,
      М-7, М-9, М-11 и региональные связки. Длина, класс, качество

Набиваем руками. Для такого объёма это час работы и точнее любого импорта.

### Симуляция

- [ ] `sim/types.ts` — типы состояния из документа архитектуры
- [ ] `sim/rng.ts` — детерминированный ГПСЧ на сиде
- [ ] `sim/world/projection.ts` — широта/долгота → плоскость
- [ ] `sim/world/graph.ts` — построение графа, соседи, доступ к рёбрам
- [ ] `sim/world/pathfind.ts` — Дейкстра по времени в пути, кэш путей
- [ ] `sim/state.ts` — начальное состояние из данных
- [ ] `sim/tick.ts` — фазы: время, движение. Остальные фазы заглушками
- [ ] `sim/logistics/vehicle.ts` — движение по ребру, скорость от класса дороги
      и качества, накопление километража

### Приложение

- [ ] `app/store.ts` — Zustand держит состояние, вызывает тик
- [ ] `app/loop.ts` — игровой цикл, число тиков за кадр, скорости ×1/×2/×5, пауза

### Рендер

- [ ] `render/Scene.tsx` — изометрическая камера, орбита и зум, свет
- [ ] `render/RoadMesh.tsx` — дороги сплайнами, толщина по классу
- [ ] `render/CityMesh.tsx` — процедурные кластеры коробок, сид от `cityId`,
      силуэт зависит от населения
- [ ] `render/VehicleMesh.tsx` — инстансинг, интерполяция позиции между тиками
- [ ] `render/postprocessing.ts` — bloom, тонмаппинг, зерно, виньетка
- [ ] Палитра и стилевой замок: холодная база плюс оранжевый акцент

### Интерфейс

- [ ] Дата, время суток, скорость, пауза
- [ ] Клик по городу — панель с названием и населением
- [ ] Отладочная кнопка: отправить машину из A в B

### Тесты

- [ ] Проекция: известные координаты дают ожидаемые точки
- [ ] Граф: связность, симметричность
- [ ] Путь: кратчайший маршрут между известными городами совпадает с ручным расчётом
- [ ] Движение: машина за N тиков проходит ожидаемое расстояние
- [ ] Детерминизм: одинаковый сид и одинаковые действия дают идентичное состояние
- [ ] Playwright: сцена рендерится, ошибок в консоли нет

### Готовность среза

Открываешь ссылку — видишь изометрическую карту центральной России с городами и
трассами, идёт время, можно поставить на паузу и ускорить, машина едет из Москвы
в Тулу по реальному маршруту, и это прилично выглядит.

## Срез 2: Экономика — набросок

Расписывать детально буду по завершении первого. Крупно:

Предприятия с рецептами, производство и потребление, склады, деньги за
доставленный груз, потребление и рост городов, деградация предприятий при
простое. Появляется ручная отправка машины с грузом и первая прибыль.

Ключевой вопрос среза, который решится только на практике: **какая
гранулярность груза даёт интересные решения** — тонны, паллеты, условные партии.
От этого зависит вся экономика, и угадывать заранее бессмысленно.

## Как я работаю по ходу

- Каждый срез начинается с уточнения детального плана и заканчивается прогоном
  тестов и деплоем
- Коммиты осмысленные, история — часть портфолио
- `prompts/` пополняется по мере генерации ассетов
- Баланс настраивается прогонами симуляции, а не на глаз
- После каждого среза — короткий отчёт: что сделано, что узнали, что меняем в плане
